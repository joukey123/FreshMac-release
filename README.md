<h1 align="center">FreshMac</h1>
<p align="center">맥을 깔끔하게 정리해주는 작은 앱 · 지우기 전에 항상 보여주고, 대부분은 휴지통으로만 옮겨요</p>

## 다운로드

| 내 맥 | 받기 |
|---|---|
| 애플 실리콘 (M1·M2·M3·M4 등) | [**FreshMac-AppleSilicon.dmg**](https://github.com/joukey123/FreshMac-release/releases/latest/download/FreshMac-AppleSilicon.dmg) |
| 인텔 | [**FreshMac-Intel.dmg**](https://github.com/joukey123/FreshMac-release/releases/latest/download/FreshMac-Intel.dmg) |

내 맥이 어느 쪽인지 모르겠으면 화면 왼쪽 위  › **이 Mac에 관하여**에서 "칩"이 Apple로 시작하면 애플 실리콘, "프로세서"가 Intel이면 인텔이에요.

## 설치

1. 받은 DMG를 열고 **FreshMac**을 **Applications** 폴더로 끌어다 놓아요.
2. 처음 열 때 "확인할 수 없음" 경고가 뜨면 **완료**를 눌러요.
3. **시스템 설정 › 개인정보 보호 및 보안**에서 아래쪽 **그래도 열기**를 눌러요. 처음 한 번만 하면 돼요.

그다음부터는 앱 왼쪽 아래 **업데이트** 버튼으로 새 버전을 받을 수 있어요.

## 할 수 있는 것

- **AI 작업 폴더**: Codex 작업을 프로젝트별로 보고 압축 보관·정리
- **자동 정리**: 정해진 주기로 안전한 항목만 정리, 저장 공간 부족 알림
- **스마트 스캔**: AI 앱·브라우저 캐시, 중복 빌드 폴더, 개발 찌꺼기, 시스템 정크·시스템 데이터, 오래된 다운로드, 지운 앱의 흔적, 대용량·중복 파일, 빈 파일·폴더
- **내 맥**: 저장 공간·메모리·CPU·배터리 상태, 메모리를 많이 쓰는 앱 종료
- **메뉴 막대**: 오른쪽 위에 CPU·메모리·남은 저장 공간 표시
- **개인정보**: 브라우저별 방문 기록·다운로드 기록·자동완성·쿠키 (직접 고른 것만)
- **앱 완전 삭제**, **앱 열기 허용**(그래도 열기), **휴지통** 정리

## 건드리지 않는 것

저장된 비밀번호·키체인·북마크, Claude·ChatGPT 같은 AI 앱의 대화 이력과 기억. 서버로 보내는 데이터도 없어요.
